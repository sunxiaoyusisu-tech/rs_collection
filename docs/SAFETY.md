# 安全说明

## 启动前

- 从臂周围不得有人、线缆或障碍物。
- 急停或物理断电手段必须伸手可及。
- 主臂和从臂应放在相近、安全的姿态，避免恢复对齐检查通过后产生突跳。
- 确认 PCAN-USB 对应 `can0`，波特率为 1 Mbps。
- 确认没有其他进程占用 CAN 或主臂串口。

## 运行中

- 不要同时运行 `run_collection` 与 `run_teleop`。
- 出现持续大电流声、异响、自激往复或不可预测动作时，立即 Ctrl+C；若软件未及时
  停止，直接急停/断电。
- 不要仅因为 RQT 画面正常就认为控制器和录包均正常，应检查终端 diagnostics 与
  录制结束后的实测频率。

## 停止

`run_collection` 的 Ctrl+C 路径会：

1. 停止 rosbag 并等待索引落盘。
2. 向 ROS 2 launch 进程组发送 SIGINT。
3. 停止主臂读取、相机和 RQT。
4. 执行最终从臂 `estop()` 失能。

如果终端长时间停在“正在停止”，应首先确认从臂已物理安全，再在另一个终端检查残留
进程；不要在不确定状态下重新启动第二条控制链路。
